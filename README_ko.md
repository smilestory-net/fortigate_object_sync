# 포티게이트 객체 동기화 도구 (FortiGate Object Sync)

> 여러 대의 FortiGate 방화벽 설정 파일(`.conf`) 또는 멀티 vDOM 환경 간의 **주소(Address) 및 서비스(Service) 객체**를 비교·분석하고, 충돌하는 속성을 손쉽게 일원화하여 **FortiOS 표준 동기화 CLI 스크립트**를 자동 생성하는 도구입니다.

## 📌 주요 기능

* **멀티 파일 및 멀티 vDOM 완벽 지원**
  * 단일 vDOM(root) 및 복수 vDOM(`config vdom`) 구조를 자동으로 감지하여 파싱합니다.
  * 여러 conf 파일 간 동일한 이름의 객체가 서로 다른 속성(IP, 서브넷, FQDN, 코멘트, 멤버 등)을 가질 경우 즉시 충돌(Conflict)로 식별합니다.

* **직관적인 속성 통합 워크플로우**
  * **단일 객체**: 기준이 될 vDOM을 선택하면, 해당 정의가 다른 모든 대상 vDOM에 적용되는 CLI(`set`/`unset`)를 생성합니다.
  * **그룹 객체**: 모든 vDOM의 멤버를 하나로 묶는 **[Merge (합집합)]** 또는 특정 vDOM의 멤버 구성을 그대로 덮어쓰는 **[선택한 vDOM으로 덮어쓰기]** 방식을 지원합니다.
  * **그룹 멤버 맞춤 편집 (+)**: 그룹 객체에서 '선택한 vDOM으로 덮어쓰기' 모드 선택 시, 기준 vDOM 카드 상단의 `+` [멤버 편집] 버튼을 통해 전체 vDOM의 멤버 풀(Merge 합집합)을 조회하고 실시간 검색 및 체크박스를 통해 최종 멤버 구성을 자유롭게 추가/제외할 수 있습니다.
  * **중첩 그룹 의존성 자동 해결(Closure)**: 그룹에 포함된 하위 멤버 객체들도 대상 vDOM에 누락되지 않도록 자동으로 생성 목록에 포함하며, CLI 생성 시 **하위 객체 생성 ➔ 상위 그룹 생성** 순서로 명령어 순서를 보장합니다.

* **이름 통합 (동일 속성 중복 객체 일원화)**
  * **속성 100% 일치 중복 탐지**: 기능적 속성(IP/서브넷, FQDN, 포트범위, 멤버 구성)은 완전히 동일하나 이름만 다른 객체(예: `HTTP` vs `WEB`, `WAS_SRV` vs `WEB_APP`)를 자동 식별합니다.
  * **장비 기본(디폴트) 객체 자동 제외**: FortiOS에 사전 내장된 시스템 기본 객체(`all`, `FTP_GET`, `FTP_PUT`, `EMS_ALL_UNKNOWN_CLIENTS`, `FCTEMS_ALL_FORTICLOUD_SERVERS` 등)는 이름 통합 군집 및 비교 보고서 대상에서 자동으로 제외하여 불필요한 분석 노이즈를 방지합니다.
  * **전방위 참조 위치 자동 스캔**: 방화벽 정책(`firewall policy`, `proxy-policy`), 중앙 NAT(`central-snat-map`), VIP/DNAT(`firewall vip`), 로컬 인 정책(`local-in-policy`), DoS 정책 및 인터페이스 ACL, IPsec VPN(Phase 2 선택기), SSL-VPN(스플릿 터널링), 정책 기반 라우팅(PBR `router policy`), 정적 라우팅, 객체 그룹 등 FortiOS 내의 모든 참조 위치를 정밀하게 추적합니다.
  * **안전한 Opt-in 선택 방식**: 기본값은 **[기존 유지 (통합 안함)]**으로 설정되어 CLI에 아무런 영향을 주지 않으며, 관리자가 표준으로 사용할 객체명을 직접 선택한 경우에만 해당 군집의 모든 참조를 표준 객체명으로 교체하고 구 객체를 삭제(`delete`)하는 안전한 CLI 스크립트를 생성합니다.
  * **단일 vDOM 정리 지원**: 여러 파일 비교뿐만 아니라 단일 장비/단일 vDOM 설정에서도 동일 속성 중복 객체를 감지하여 단일 표준명으로 깔끔하게 정리할 수 있습니다.
  * **전용 HTML 보고서 3종**: 동일 속성 객체 군집 및 참조 위치를 한눈에 파악할 수 있는 인터랙티브 HTML 보고서(`report_fgt_diff_identical_def.html`)를 비롯해 총 3종의 전용 보고서를 자동 생성합니다.

* **작업 상태 저장 및 불러오기 (세션 이어하기)**
  * 검토할 객체가 많아 작업을 나누어 진행할 때, 언제든지 **`[작업 저장]`** 버튼을 눌러 진행 상황을 세션 파일(`.fgtsync`)로 저장할 수 있습니다.
  * 프로그램 재실행 시 또는 다른 관리자 PC에서 **`[파일 선택]`**으로 `.fgtsync` 세션 파일을 직접 선택하면, 원본 설정 스냅샷과 사용자가 선택해 둔 기준값들이 100% 즉각 복원되어 원본 conf 파일 없이도 언제든 작업을 이어가거나 CLI를 생성할 수 있습니다.

* **정밀한 4단계 Diff 시각화**
  * **유지 (동일)**: 기준과 동일한 속성은 일반 텍스트로 표시
  * **수정 (값 변경)**: 변경 대상 속성은 노란색 하이라이트(마우스 호버 시 변경 목표값 툴팁)로 표시
  * **삭제 (제거)**: 기준 정의에서 제거되는 속성 및 그룹 멤버는 앞에 `-` 기호와 함께 빨간색(`-속성명` / `-멤버`)으로 표시
  * **추가 (신규)**: 새롭게 추가되는 속성 및 그룹 멤버는 앞에 `+` 기호와 함께 초록색(`+속성명` / `+멤버`)으로 표시
  * **미선택 상태 격리**: 기준을 선택하기 전에는 수정/변경없음 태그를 숨겨 불필요한 혼란을 방지하고 원본 속성만을 비교할 수 있도록 지원

* **조건별 고속 검색 및 ESC 단축키 지원**
  * **기본 검색 (따옴표 없음)**: 입력한 문자열 그대로 정확한 부분 일치(Substring) 검색을 수행합니다 (예: `성과 시스템` 입력 시 해당 구문이 그대로 들어간 객체 검색).
  * **다중 단어 검색 (작은따옴표 `' '` 사용)**: 검색어를 작은따옴표로 감싸면(예: `'성과 시스템'`) 단어들의 앞뒤 배치 순서와 상관없이 모든 단어가 포함된 객체(`[WAS]IR 성과관리시스템-1`, `성과시스템`, `시스템이다성과` 등)를 AND 조건으로 검색 및 동시 하이라이트합니다.
  * **ESC 단축키 지원**:
    * **1회 입력**: 검색창 입력값을 즉시 초기화합니다. 마지막으로 선택했던 객체의 선택 상태 및 화면상의 시각적 위치(상단, 중간 등)가 그대로 제자리에 유지됩니다.
    * **연속 2회 입력 (450ms 이내 빠른 연타)**: 검색창 입력값뿐만 아니라 종류(`Kind`), 타입(`Type`) 필터까지 전체 초기화합니다. 선택 상태 및 화면상의 시각적 위치는 그대로 유지됩니다.

* **CLI 미리보기 검색 & 위치 이동**
  * 생성된 CLI 스크립트에서도 동일한 검색 방식 지원
  * 일치 항목 카운터(`1 / N`), 이전/다음 화살표 버튼(`▲`/`▼`) 및 `Enter` / `Shift+Enter` 순차 이동 지원

* **다크 모드 및 라이트 모드 지원**
  * 라이트 테마(시스템/소프트 라이트) 및 다크 테마(앤티그래비티 다크/사이버 다크)를 지원하여 사용자 환경에 맞추어 전환할 수 있습니다.

* **해상도 맞춤 UI 스케일링**
  * 80% ~ 125% 등 비율 조절 프리셋 및 직접 입력(%) 지원
  * 가로 길이가 균일하게 정돈된 액션 버튼 기본 제공

## 🚀 프로그램 실행 방법

1. 다운로드한 `fortigate_duplicate_diff_v1.5.zip` 파일의 압축을 풉니다.
2. 폴더 내의 **`fortigate_duplicate_diff.exe`** 파일을 더블 클릭하여 실행합니다.
3. **신규 분석 시작**:
   * **[파일 선택]** 버튼을 눌러 비교·분석할 포티게이트 백업 설정 파일(`.conf` 또는 `.txt`)을 1개 이상 선택합니다.
   * 필요 시 **저장 폴더** 경로를 지정합니다 (기본값: 첫 번째 파일 위치).
   * **[분석]** 버튼을 클릭하여 분석을 시작합니다.
4. **기존 작업 이어하기 (세션 불러오기)**:
   * **[파일 선택]**에서 이전에 저장해 둔 `.fgtsync` 세션 파일을 직접 선택합니다.
   * 설정 파일 재선택 없이도 이전 분석 내용과 선택 상태가 즉시 100% 복원됩니다.

## 📖 상세 사용 방법

### 1. 설정 파일 분석 또는 세션 불러오기
* **신규 분석**:
  * **Config 파일**: 분석할 FortiGate `.conf` 또는 `.txt` 파일 선택 (`[파일 선택]`)
    * 우측의 **`[ 접기/펼치기 (▼/▶) ]`** 아이콘 버튼으로 설정 카드 영역을 1줄로 축소(선택 파일 수 및 저장 경로 요약 표시)하거나 다시 펼쳐 작업 화면을 넓힐 수 있습니다.
  * **저장 폴더**: CLI 스크립트 및 보고서가 저장될 폴더 지정 (기본값: 첫 번째 파일 위치)
  * **옵션**: 완료 후 `저장 폴더 자동 열기`, `보고서 저장` 여부 체크
  * **[분석] 버튼 클릭**: vDOM 구조와 방화벽 객체를 고속 스캔하고 충돌/누락 항목을 식별합니다. 분석이 완료되면 중복 분석 방지를 위해 **`[분석]`** 버튼이 비활성화되며, 다시 **`[파일 선택]`**으로 새 파일을 지정하기 전까지 비활성화 상태가 유지됩니다.
  * **스마트 분석 안내**:
    * 단일 파일이면서 단일 vDOM인 경우 등 비교 분석 조건이 성립하지 않으면 안내 팝업을 표시합니다.
    * 여러 파일을 분석했더라도 중복 이름 객체가 없거나 모든 중복 객체의 속성이 동일하여 변경할 항목이 없는 경우 안내 팝업을 통해 즉시 알려줍니다.
* **작업 불러오기 (세션 이어하기)**:
  * **`[파일 선택]`**에서 `.fgtsync` 세션 파일을 선택하면 이전 작업 상태(모든 객체 스냅샷, 선택한 라디오 버튼, 그룹 모드)가 원본 설정 파일 없이도 즉시 복원됩니다.

### 2. '속성 통합' 탭 사용법
* **객체 목록 탐색 및 필터링**:
  * 좌측 목록에서 주황색 `[속성 다름]` 또는 빨간색 `[미선택]` 태그가 표시된 객체를 클릭합니다.
  * **드롭다운 필터**: 객체 종류(전체/충돌/누락), 객체 타입(전체/주소/주소그룹/서비스/서비스그룹)으로 원하는 항목만 필터링할 수 있습니다.
  * **검색 기능**:
    * 일반 검색: 검색어 입력 시 정확한 부분 일치 검색 수행
    * 다중 단어 검색: 작은따옴표로 감싸 입력(`'단어1 단어2'`) 시 단어 순서와 무관하게 모든 단어가 포함된 객체를 동시 검색
  * **ESC 단축키**:
    * **`ESC` 1회**: 검색어 즉시 초기화 (현재 선택된 객체와 화면 스크롤 위치 유지)
    * **`ESC` 2회 빠르게 연타 (450ms 이내)**: 검색어 및 모든 드롭다운 필터 전체 초기화 (선택 상태 및 화면 위치 유지)
* **충돌 객체 기준 선택 및 초기화**:
  * **단일 객체 (Address / Service)**: 우측 화면에서 각 vDOM별 속성 차이를 확인한 후, 기준이 될 vDOM의 라디오 버튼을 선택합니다.
  * **그룹 객체 (Addrgrp / Service Group)**:
    * `[Merge (합집합)]`: 모든 vDOM의 멤버를 결합한 통합 그룹을 대상 vDOM에 동기화합니다.
    * `[선택한 vDOM으로 덮어쓰기]`: 기준 vDOM을 선택하여 해당 멤버 구성으로 대상 vDOM들을 일원화합니다.
    * **멤버 맞춤 편집 (`+` 버튼)**: 기준 vDOM 카드 우측 상단의 `+` 버튼을 클릭하면, 해당 그룹 객체의 모든 vDOM 멤버가 취합된 풀(Pool) 모달 창이 열립니다. 실시간 검색창, 전체 선택/해제, 기준값 복원 기능을 제공하며, 체크박스를 통해 최종 반영할 멤버를 직접 추가하거나 제외할 수 있습니다. 커스텀 편집된 멤버는 세션 파일(`.fgtsync`) 및 CLI 생성에도 그대로 반영됩니다.
  * **선택 초기화 (🔄)**: 우측 상단에 상시 배치되며, 기준 선택 전이나 선택 대상이 아닌 객체(누락 객체 등)에서는 비활성화(disabled) 상태로 대기합니다. 객체 기준(라디오 버튼, Merge, Overwrite)을 지정한 후 재판단이 필요할 때 활성화된 **`[선택 초기화 (🔄)]`** 버튼을 누르면 해당 객체의 선택이 취소되고 초기 `[미선택]` 상태로 즉시 복원됩니다.
* **진행 상황 저장**:
  * 검토 도중 언제든 **`[작업 저장]`** 버튼을 클릭하여 `.fgtsync` 파일로 저장할 수 있습니다.

### 3. '이름 통합' 탭 사용법 (NAME SYNC)
* **군집 목록 탐색 & 필터링**:
  * 속성값이 100% 일치하는 중복 객체 군집이 좌측 목록에 카드 형태로 표시됩니다 (예: `HTTP_SRV`, `WEB_SRV`).
  * 장비 디폴트로 사전 정의된 기본 시스템 객체(`all`, `FTP_GET`, `FTP_PUT`, `EMS_ALL_UNKNOWN_CLIENTS`, `FCTEMS_ALL_FORTICLOUD_SERVERS` 등)는 군집 비교 대상에서 자동으로 제외되므로 사용자 정의 객체에만 집중할 수 있습니다.
  * 상단 드롭다운으로 객체 타입(주소/서비스/그룹)을 필터링하거나 검색창을 통해 객체명, IP, 포트 번호를 실시간 검색할 수 있습니다.
* **표준 객체명 선택 (Opt-in 방식)**:
  * 우측 상단 카드의 라디오 버튼에서 통일하고자 하는 **표준 객체명**을 선택합니다 (예: `"HTTP_SRV" (으)로 통합`).
  * 선택 즉시 해당 vDOM 내에서 다른 중복 객체(`WEB_SRV`)를 참조하고 있던 정책, NAT, VPN, 그룹, 라우팅의 참조가 표준 객체명으로 치환되며, 구 객체는 안전하게 삭제(`delete`)하는 스크립트가 CLI에 자동 반영됩니다.
  * 기본 상태인 **[기존 유지]**를 선택하거나 미선택 상태로 두면 해당 객체는 변경되지 않고 원본 그대로 유지됩니다.
* **객체별 참조 현황 확인**:
  * 하단 '객체별 참조 현황'에서 각 객체가 현재 방화벽 정책, VIP, NAT, VPN, 라우팅 등 어디에서 몇 번 참조되고 있는지 상세 테이블(위치, 필드명)로 확인할 수 있습니다.

### 4. 'CLI 미리보기' 탭 사용법
* 상단의 파일별 탭을 클릭하여 각 방화벽 장비에 적용될 FortiOS CLI 스크립트를 실시간으로 확인합니다.
* 이름 통합 탭에서 선택한 내용도 CLI 하단에 자동으로 의존성 순서(그룹 ➔ VIP ➔ VPN ➔ 라우팅 ➔ 정책/NAT ➔ 구 객체 삭제)에 맞추어 생성됩니다.
* **검색 & 이동**: 검색창에 키워드를 입력하고 `▲`/`▼` 버튼 또는 `Enter` / `Shift+Enter`로 일치 항목을 순차 탐색합니다.
* **전체 복사**: 우측 상단의 `복사` 버튼을 눌러 생성된 스크립트 전체를 클립보드에 복사할 수 있습니다.

### 5. '속성 비교', '속성 통합 참조', '이름 비교' 탭 (HTML 보고서)
* **속성 비교 (PROPERTY DIFF)**: vDOM 간 객체 속성 차이를 한눈에 비교하는 인터랙티브 HTML 보고서를 GUI 내에서 바로 확인합니다.
* **속성 통합 참조 (PROPERTY SYNC REF)**: 다른 vDOM의 참조로 인해 대상 vDOM에 추가 생성이 필요한 객체 목록(`Object creation required`)을 확인합니다.
* **이름 비교 (NAME DIFF)**: 속성이 100% 동일한 중복 객체 군집 및 참조 위치를 종합 분석한 인터랙티브 보고서를 확인합니다.
* **브라우저에서 열기**: 분석 완료 후 각 보고서 탭 상단의 `[브라우저에서 열기]` 버튼을 통해 기본 웹 브라우저에서 전체 화면으로 열람할 수 있습니다.

### 6. CLI 스크립트 생성 및 '콘솔' 확인
* 속성 통합 및 이름 통합 선택 완료 후 상단의 **`[CLI 생성]`** 버튼을 클릭합니다.
* 지정된 저장 폴더에 각 conf 파일별 동기화 스크립트(`report_diff_command_<파일명>.txt`) 및 3종의 HTML 보고서(속성 비교 보고서, 객체 속성 통합 참조 보고서, 동일 속성 중복 정의 보고서)가 생성됩니다.
* **`콘솔`** 탭에서 스크립트 생성 완료 로그 및 실시간 처리 결과를 확인합니다.
* **`[저장 폴더 열기]`** 버튼을 클릭하여 결과물이 저장된 탐색기 폴더를 바로 열 수 있습니다.

---

## 🛡️ 안전성 및 주의사항

* 본 도구가 생성하는 CLI 스크립트는 **방화벽 객체의 생성(`edit` / `set`) 및 불필요 속성 초기화(`unset`)**만 수행합니다.
* 방화벽 정책(Policy)이나 다른 설정 블록을 임의로 삭제하지 않으므로 안전하게 운영 환경에 반영할 수 있습니다.
* 실제 방화벽 장비에 적용하기 전, `CLI 미리보기` 탭을 통해 생성된 스크립트가 의도와 일치하는지 최종 검토하시기를 권장합니다.
