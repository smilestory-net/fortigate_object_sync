# 포티게이트 객체 동기화 도구 (FortiGate Object Sync)

> 여러 대의 FortiGate 방화벽 설정 파일(`.conf`) 또는 멀티 vDOM 환경 간의 **방화벽 주소(Address) 및 서비스(Service) 객체**를 비교·분석하고, 충돌하는 속성을 손쉽게 일원화하여 **FortiOS 표준 동기화 CLI 스크립트**를 자동 생성하는 도구입니다.

## 📌 주요 기능

* **멀티 파일 및 멀티 vDOM 완벽 지원**
  * 단일 vDOM(root) 및 복수 vDOM(`config vdom`) 구조를 자동으로 감지하여 파싱합니다.
  * 여러 conf 파일 간 동일한 이름의 객체가 서로 다른 속성(IP, 서브넷, FQDN, 코멘트, 멤버 등)을 가질 경우 즉시 충돌(Conflict)로 식별합니다.

* **직관적인 의사결정(Decision) 워크플로우**
  * **단일 객체**: 기준이 될 vDOM을 선택하면, 해당 정의가 다른 모든 대상 vDOM에 적용되는 CLI(`set`/`unset`)를 생성합니다.
  * **그룹 객체**: 모든 vDOM의 멤버를 하나로 묶는 **[Merge (합집합)]** 또는 특정 vDOM의 멤버 구성을 그대로 덮어쓰는 **[선택한 vDOM으로 덮어쓰기]** 방식을 지원합니다.
  * **중첩 그룹 의존성 자동 해결(Closure)**: 그룹에 포함된 하위 멤버 객체들도 대상 vDOM에 누락되지 않도록 자동으로 생성 목록에 포함하며, CLI 생성 시 **하위 객체 생성 ➔ 상위 그룹 생성** 순서로 명령어 순서를 보장합니다.

* **정밀한 4단계 Diff 시각화**
  * **유지 (동일)**: 기준과 동일한 속성은 일반 텍스트로 표시
  * **수정 (값 변경)**: 변경 대상 속성은 노란색 하이라이트(마우스 호버 시 변경 목표값 툴팁)로 표시
  * **삭제 (제거)**: 기준 정의에서 제거되는 속성은 취소선과 함께 `(삭제)` 표시
  * **추가 (신규)**: 새롭게 추가되는 속성은 초록색 `+ 속성명 (추가)` 표시
  * **미선택 상태 격리**: 기준을 선택하기 전에는 수정/변경없음 태그를 숨겨 불필요한 혼란을 방지하고 원본 속성만을 비교할 수 있도록 지원

* **조건별 고속 검색 및 ESC 단축키 지원**
  * **기본 검색 (따옴표 없음)**: 입력한 문자열 그대로 정확한 부분 일치(Substring) 검색을 수행합니다 (예: `성과 시스템` 입력 시 해당 구문이 그대로 들어간 객체 검색).
  * **다중 단어 검색 (작은따옴표 `' '` 사용)**: 검색어를 작은따옴표로 감싸면(예: `'성과 시스템'`) 단어들의 앞뒤 배치 순서와 상관없이 모든 단어가 포함된 객체(`[WAS]IR 성과관리시스템-1`, `성과시스템`, `시스템이다성과` 등)를 AND 조건으로 검색 및 동시 하이라이트합니다.
  * **ESC 단축키 지원**:
    * **1회 입력**: 검색창 입력값을 즉시 초기화합니다. 이 때 마지막으로 선택했던 객체의 선택 상태 및 화면상의 시각적 위치(상단, 중간 등)가 그대로 제자리에 유지됩니다.
    * **연속 2회 입력 (450ms 이내 빠른 연타)**: 검색창 입력값뿐만 아니라 종류(`Kind`), 타입(`Type`) 필터까지 전체 초기화합니다. 선택 상태 및 화면상의 시각적 위치는 그대로 유지됩니다.

* **CLI 미리보기 검색 & 위치 이동**
  * 생성된 CLI 스크립트에서도 동일한 검색 방식 지원
  * 일치 항목 카운터(`1 / N`), 이전/다음 화살표 버튼(`▲`/`▼`) 및 `Enter` / `Shift+Enter` 순차 이동 지원

* **해상도 맞춤 UI 스케일링**
  * 80% ~ 125% 등 비율 조절 프리셋 및 직접 입력(%) 지원

## 🚀 프로그램 실행 방법

1. 다운로드한 `fortigate_duplicate_diff_v1.0.zip` 파일의 압축을 풉니다.
2. 폴더 내의 **`fortigate_duplicate_diff.exe`** 파일을 더블 클릭하여 실행합니다.
3. **[Select Files...]** 버튼을 눌러 비교·분석할 포티게이트 백업 설정 파일(`.conf` 또는 `.txt`)을 1개 이상 선택합니다.
4. 필요 시 결과 저장 경로(`Output Directory`)를 지정합니다 (기본값: 첫 번째 파일 위치).
5. **[ANALYZE]** 버튼을 클릭하여 분석을 시작합니다.


## 📖 사용 방법

1. **설정 파일 및 출력 폴더 선택**
   * **Config 파일**: 분석할 FortiGate `.conf` 또는 `.txt` 파일 1개 이상 선택
   * **출력 폴더**: CLI 스크립트 및 HTML 보고서가 저장될 폴더 지정 (기본값: 첫 번째 파일 위치)
   * 옵션: 완료 후 결과 폴더 자동 열기, HTML 보고서 함께 저장 여부 체크

2. **[ANALYZE] (분석) 실행**
   * 상단의 **`ANALYZE`** 버튼 클릭
   * 각 파일과 vDOM 구조, 방화벽 객체를 고속으로 스캔하고 충돌 항목을 목록화합니다.

3. **결정(Decision) 작업**
   * 좌측 목록에서 주황색 `[속성 다름]` 또는 빨간색 `[미선택]` 태그가 붙은 객체 선택
   * **단일 객체**: 우측 화면에서 기준이 될 vDOM의 라디오 버튼 선택
   * **그룹 객체**: 상단에서 `[Merge (합집합)]` 또는 `[선택한 vDOM으로 덮어쓰기]` 선택
   * **검색 및 필터 초기화**:
     * 상단 검색창에서 객체 이름을 빠르게 필터링 가능
     * **`ESC` 1회 누름**: 검색어 초기화 (선택한 객체 및 현재 화면 위치 유지)
     * **`ESC` 2회 빠르게 누름**: 검색어 + 종류/타입 필터 전체 초기화 (선택한 객체 및 현재 화면 위치 유지)

4. **[GENERATE CLI] (CLI 생성) 실행**
   * 모든 충돌 객체에 대한 결정이 끝나면 **`GENERATE CLI`** 버튼 클릭
   * 출력 폴더에 각 conf 파일별 동기화 CLI 스크립트(`report_diff_command_<파일명>.txt`)가 생성됩니다.
   * `CLI 미리보기` 탭에서 생성된 FortiOS 명령어를 즉시 확인하고 복사할 수 있습니다.

## 🛡️ 안전성 및 주의사항

* 본 도구가 생성하는 CLI 스크립트는 **방화벽 객체의 생성(`edit` / `set`) 및 불필요 속성 초기화(`unset`)**만 수행합니다.
* 방화벽 정책(Policy)이나 다른 설정 블록을 임의로 삭제하지 않으므로 안전하게 운영 환경에 반영할 수 있습니다.
* 실제 방화벽 장비에 적용하기 전, `CLI 미리보기` 탭을 통해 생성된 스크립트가 의도와 일치하는지 최종 검토하시기를 권장합니다.
